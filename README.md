# Autonomous-Light-Dark-Stimulus-System-for-Zebrafish-Behavioral-Studies

A custom-built light-dark stimulus system for enabling automated behavioural study experiments on juvenile zebrafish. The system uses an Arduino microcontroller to support automatic LED control and water temperature monitoring, and a PySide6 Python GUI for customizable video recording and automatic data acquisition. The complete system architecture consists of the software application, firmware, and hardware.
